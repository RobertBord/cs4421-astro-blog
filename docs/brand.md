# F1 bits identity

Original project artwork: the F-and-square icon is an editorial initial and a
small "bit", not Formula 1's official mark. SVG sources live in public/brand.
Use wordmark.svg on light backgrounds and wordmark-light.svg on dark backgrounds.
Use icon.svg for compact applications; keep its square aspect ratio and avoid
rendering the full wordmark narrower than 138px. Keep one icon-stroke of clear space.

Palette: ink #191c1b, paper #f7f8f6, editorial red #b71925, teal #11675f.
Red/white and teal/white are text-safe combinations; mint #91d6c5 is decorative.
Palatino/Georgia display headings pair with the existing locally hosted Atkinson
body font. Section spacing, colours, and typography are CSS custom properties.
Editorial images use a 16:10 crop, square corners, and visible source credits.

social.svg is the source for the 1200x630 sharing PNG. Raster exports are made
with the existing Sharp dependency. These original assets contain no third-party
photographs or official motorsport marks. F1 bits is an independent publication,
not affiliated with Formula 1, the FIA, or any team.
